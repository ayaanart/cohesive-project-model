# ID4

## Summary
A session of brainstorming a solution to a problem.

## Export Content
A session at brainstorming a solution to a problem.
A session is defined as:
1. Defining the problem you want to solve
2. Attempting to solve it, you can have as many attempts you want until you find a solution you are happy with
3. Document the solution you are going forward with
After step 3 is complete the session is finished.
If later you are not happy with the solution you chose you have to start a new [self];
you can not continue the same session, but you can target the same problem,
only this time you have more experience, and you can use your previous [self] for inspiration.
If you quit a [self] before it is done you can continue it whenever you like.
[self] does not control how you do the steps, only what these steps are.
