## Summary

## Export Content
A folder that holds the contents of all [Brainstorm Session]-s.
The folder is located at the project's root folder.
Inside [self] every [Brainstorm Session] is given their own folder.
The name of that folder is: `<#>-<keyword>-<keyword>`.
<#> is which number [Brainstorm Session] this is;
if it is the first [Brainstorm Session] for this project it will be 1.
<keyword> is a keyword to describe what you are trying to brainstorm.
Inside each session's folder are all the:
- [Brainstorm Attempt File]-(s)
- [Brainstorm Result File]
- [Brainstorm Goal File]
Related to this particular [Brainstorm Session].
