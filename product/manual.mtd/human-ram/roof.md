# ID1

## Summary
An item that is deliberately used to aid your active memory.

## Export Content
An item that is deliberately used to aid your active memory.
The item can have other functions, but it must be used to aid your short-term memory.
If an item is used to aid your long-term memory but not your short-term memory then it is not a [self].
If an item is used to aid your long-term memory and your short-term memory then it is a [self],
because it aids the short-term memory; the fact that it aids long-term memory is not considered.

### Usage Example
You are going shopping and you want a list of things to shop for.
You only need this list for the 1 shopping trip.
You take your phone out and use a note taking app to write down what you want to shop for during this trip.
Your phone is now a [self], as it is aiding your short-term memory.
You could have just used your head to remember what to shop for but you chose to use the phone for help.
Later after you finish shopping you delete the note you made,
because you no longer need it; if you want to see what you shopped for, you can look at your receipt.
Destroying and/or deleting a [self] or a part of it is not required,
but this demonstrates the fact it is not long lived.
You can still use your phone for the many other things while it still being considered a [self].

### Analogy
[self] : short-term memory :: RAM : CPU register
