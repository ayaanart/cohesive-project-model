# ID3

## Summary
A folder to track a brainstorming session.

## Export Content
A folder to track a brainstorming session.
It is located in a folder called `brainstorming`, and that `brainstorming` folder must be in your main project folder.
The folder's name is: `<the number [self]-s in this folder + 1>_<2 keywords that describe what you are brainstorming>`.
The keywords are just to jog your memory when you look at the file name.
Inside [self] there are 2 other folders: `raw` and `result`.
Inside the raw folder there is files of the actual brainstorm that happend during this session.
The file name is `attempt-<#>` with # being which attempt it was.
If a brainstorming was unable to be uploaded and/or place in the raw folder then the attempt file will still exist,
but it will follow this format:
```
# <Title: The name if the [self] it is in.>

This brainstorming was unable to be displayed because <the reason>.
You can access this brainstorming by <say how someone can view the brainstorm>.
// If it can not be accessed then replace the above line with: "You can not access this brainstorming anywhere."
```
Inside the raw folder there is also a file called `context.md` that follows this format:
```
# <Title: The name if the [self] it is in.>

started on: <date it was started on using this format: YYYY-MM-DD>
