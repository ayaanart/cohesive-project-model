# ID3

## Summary
A file that represents a brainstorm, during a particular [Brainstorm Session].

## Export Content
A file that represents a brainstorm, during a particular [Brainstorm Session].
The file's name is:  `attempt-<#>.<extension>`, with `<#>` being what attempt this is for this [Brainstorm Session].
If it is try 3 and a markdown file then it will be: `attempt-3.md`.
The file can also have any extension, so `attempt-41.png` is also valid.
You can either do the brainstorming directly inside [self], or do it elsewhere and upload the result into [self].
For example if you did the brainstorming on a whiteboard you can take a photo of it, and use that photo as [self].
If you are unable to upload the actual brainstorming, then instead use [self] to explain the situation.
You can follow this format:
```
# Brainstorm Attempt

The actual brainstorm was not able to be uploaded, because <state-the-reason>.
You can find the actual brainstorming by <say how you can find the actual brainstorming>.
```
If a person can not find the brainstorming anywhere, then replace the last line with this:
`You can not find the actual brainstorming because <state the reason>.`
If you have something else that you want to add, then add a section below. 
For example:
```
## Important Notes
<the notes you wanted to say>
```
