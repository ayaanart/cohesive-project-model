## Export Content
The file that explains the project's goal and scope.
It is strongly suggested by the person who wrote this to call the file `goal.md` and use this format:
```
# <Title: Name of your project>

## Goal
// goal as an imperative statement

### Reason
// why that is your goal as a declarative statement

## Scope
// scope as an imperative statement

### Reason
// why is that your scope as a declarative statement
```
It is not necessary to use this format if you still explain:
- The goal and the reason of the goal
- The scope and the reason of the scope
That said, there is no reason to use a different format than the one provided,
so using this format will help you be consistent.
This file is always located at the main project folder.
